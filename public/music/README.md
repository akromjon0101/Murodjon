# Background music

Place your wedding track here as `wedding.mp3` (this exact path is referenced
in `src/data/wedding.js` as `musicSrc: '/music/wedding.mp3'`).

- Use a royalty-free / licensed instrumental piece.
- Keep it reasonably compressed (~128 kbps) so mobile visitors load it quickly.
- If no file is present, the music button simply hides itself — nothing breaks.

To use a hosted file instead, set `musicSrc` to a full `https://` URL.
