# Photo gallery

Drop your photos here named `photo-1.jpg` … `photo-6.jpg`
(`.jpg` or `.webp` — just keep the name; update `src/data/wedding.js` if you
change extensions or count).

- Portrait crop works best (cards are 4:5).
- ~1200px on the long edge, compressed — keeps mobile fast.
- Any missing file shows a soft watercolor placeholder, so the section still
  looks finished with fewer than six photos.

Captions live in `src/data/i18n.js` under `galleryCaptions` (per language).
